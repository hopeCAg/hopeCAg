## 📋 Compliance and Stig

- **[Windows-11-STIG-Remediation](https://github.com/hopeCAg/Windows-11-STIG-Remediation-/blob/main/README.md)** :Identified, remediated, and verified nine DISA STIG controls for Windows 11 spanning CAT I through CAT III severity, including account lockout policy, guest account disablement, SMB insecure logon restrictions, RDS password enforcement, and password complexity and history requirements. Complete with before-and-after scan results confirming compliance against the DoD hardening baseline.
  
## 🚨 Threat Hunting and Security Operations

- **[Threat Hunting Scenario (Tor Browser Usage)](https://github.com/hopeCAg/threat-hunting-scenario-tor-)** :Unauthorized TOR Usage Investigated unauthorized TOR browser usage on a corporate Windows endpoint, tracing the full activity chain from silent installer execution through TOR network connections to known entry nodes and the creation of a suspicious file artifact. Confirmed on a single user account and escalated to management. 
  
- **[Threat Hunting Scenario: Second Vector](https://github.com/hopeCAg/Threat-Hunt---Second-Vector)** : Investigated a cloud-only identity compromise against a finance user in a Microsoft 365 tenant, tracing the full attack chain from anonymous-IP token replay and MFA bypass through Graph API reconnaissance, payment-redirect BEC, dual Exchange inbox rule persistence, and a Power Automate flow executing silent exfiltration with no attacker session required.
